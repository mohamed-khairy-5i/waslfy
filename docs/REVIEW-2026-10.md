## The bug that mattered: label-bleed

`extractShipment('الاسم:\nالتليفون:\nالعنوان:')` returned `name = "التليفون"` with **confidence: high** — the engine picked up the *next* label word as the customer's name. Root cause: definite-article variants of field keywords (`التليفون`, `الكود`, `المبلغ`…) were missing from `STOPWORDS`/`FIELD_KEYWORDS`, so an empty label's 80-char capture window bled across lines.

**Fix** (`src/tokens.ts`): added the ال-variants to both sets — this closes capture zones for name, address *and* amount alike. **Result:** 3 regression tests added; corpus accuracy stays **40/40 (100%) on all five fields**. Shipped as `waslfy-parser@0.1.1`.

## Known cosmetic leftovers

- npm packument keeps a `0.0.0-stage` placeholder version (artifact of the new-package pipeline). Harmless — installs resolve to `latest` = 0.1.1. Removable by the account owner from npmjs.com within 72 h of publish (granular bypass-2FA tokens can't unpublish by design).
- Web bundle could shed weight later (code-splitting the receipt/print paths) — logged as future work, not a defect.
- npm tarball includes `dist/cli.*` (~330 kB unpacked). Kept intentionally so `npx` demos work; can be split out if size ever matters.
