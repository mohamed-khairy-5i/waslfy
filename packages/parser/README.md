# waslfy-parser

محرك استخراج بيانات الشحن المصرية من نص رسائل واتساب — **صفر dependencies، TypeScript نقي**.

دي حزمة `waslfy-parser` — قلب مشروع [Waslfy](../../README.md): التاجر بيعمل paste لرسالة العميلة، والحزمة بتطلّع منه الاسم والهاتف والمحافظة والعنوان ومبلغ التحصيل مع **درجة ثقة معلنة لكل حقل**.

## المبادئ

1. **مفيش قيم صامتة** — أي حقل مش متأكد منه بيرجع `confidence: low/empty`، والحزمة عمرها ما "تخمّن" قيمة وتديها شكل واثق.
2. **القيمة بالرسم الأصلي** — لو العميل كتب "مروة" بنرجّع "مروة" مش "مروه" (التطبيع بيحصل داخلياً للمطابقة بس).
3. **العنوان low بالتصميم** — العنوان العربي محتاج مراجعة بشرية، والحزمة صريحة في ده.

## الاستخدام

```ts
import { extractShipment } from 'waslfy-parser';

const r = extractShipment(
  'الاسم: محمود علي - العنوان: 15 ش شارع جامعة الدول، المهندسين، الجيزة - تليفون: 01001234567 - كود 450'
);

r.name.value;        // "محمود علي"        — confidence: high
r.phones.value;      // ["01001234567"]    — confidence: high
r.governorate.value; // { id: "giza", name: "الجيزة" } — high (من "المهندسين")
r.address.value;     // "15 ش شارع جامعة الدول" — confidence: low (بالتصميم)
r.amount.value;      // 450                — confidence: high
```

كل `Field` بيكون: `{ value, confidence: 'high'|'medium'|'low'|'empty', source, alternatives?, confirmed }`.

## الدقة (35 رسالة اختبارية منشورة في test/corpus)

| الحقل | الدقة الحالية | الهدف المعَلن |
|-------|---------------|----------------|
| الهاتف | 100% (35/35) | ≥ 98% |
| المحافظة | 100% (35/35) | ≥ 95% |
| المبلغ | 100% (35/35) | ≥ 90% |
| الاسم | 100% (35/35) | ≥ 85% |
| العنوان | 100% contains-match | low-by-design |

الـ corpus مقسوم 5 فئات: رسائل منظمة (basic) — عامية مصرية (dialect) — عربي/إنجليزي مخلوط (mixed-lang) — أرقام هندية ٠١٢٣ (arabic-numerals) — رسائل متعددة السطور زي واتساب الحقيقي (multiline).

## إمكانيات ذكية مدمجة

- تطبيع عربي: همزات، ة/ه، أرقام هندية ٠١٢→012، حروف مخفية zero-width من واتساب
- `ى` مش بتتطبع مع `ي` — عشان "على" (حرف جر) تفضل مختلفة عن "علي" (اسم)
- "ش بورسعيد" = اسم شارع، مش محافظة بورسعيد — المحرك بيفرّق بالسياق
- أرقام موبايل مصرية بكل الصيغ: `010...` / `+2010...` / `002010...` / `٠١٠...`
- المبلغ بيتبني على كلمات زي: كود/كاش/مبلغ/تحصيل/COD — ومش هياخد رقم تليفون بالغلط
- فازي-ماتش (Levenshtein ≤ 1) لأخطاء كتابة أسماء المحافظات
- 100+ مدينة/منطقة مربوطة بمحافظتها ("المنصورة" → الدقهلية، "المهندسين" → الجيزة)
- نمط "انا X عايز..." — التعريف بالنفس في الرسائل العامية
- رسائل متعددة السطور (كل سطر ممكن يكون حقل)
